## P0-1 会话摘录卡死（根因已由主会话定位，勿再全量扫盘）

根因：`lib/session-manager.mjs` `getSessionDetail`（约 245-256 行）每次点击都调 `collectAllSessions` 全量真机扫描 → 真机超时 → 宿主杀面板。摘录数据本来就在 `data/session-cache.json`（每会话每天 ≤3 条 texts，键为 source+file）。

1. `getSessionDetail` 改为**纯缓存读**：读 session-cache.json 命中 (source,file) → 组装 dates（date/turns/texts）；索引无 meta → 「会话不在索引中，请先同步会话」；缓存条目缺失 → `available:false` + 「摘录尚未同步——先点『同步会话』」。
2. **任何路径不得调用 collectAllSessions**；断言测试锁死（单测：mock 缓存有/无两条路径，断言不读源文件）。
3. panel 侧「加载完整摘录」busy 态保留；错误走统一 notice（不再可能触发宿主兜底杀面板）。
4. 顺带核查同文件 `sessions list` op 是否也有扫盘路径（有则同样改缓存读），排查结论写收据。

## P0-2 知识图谱展示重做（用户判定"太差不合理"）

资料库 → 图谱子视图重做，**自绘 SVG，不引外部依赖**（面板自包含纪律）：

1. 实体层：类型 chips 保留；实体列表改**卡片网格**（实体名 + 类型徽标 + 关系条数），替换纯文本行。
2. 点实体 → **邻域图**：该实体居中，关系为辐条（SVG 边 + 边上关系动词 + 对端节点圆角矩形，节点颜色按类型），对端节点可点击继续遍历，面包屑/返回按钮回列表。布局用确定性排布（环形/辐条），**不做力导向**。
3. 邻域图下方保留文字版关系明细（可达性兜底）。
4. 「更新图谱」按钮与确认语义不变。
