## 具体改动

1. **术语替换**（全面板用户可见字符串，src/panel.js + 必要时 hook/server 的用户可见文案；代码内部标识符不改名）：
   - 采集条目/统一条目 → 记录；入库会话 → 已同步会话；一键同步全部历史会话 → 同步会话
   - 指纹扫描 → 增量扫描；补偿式调度 → 定时任务（错过的自动补跑）；监控目录指纹 → 监控目录增量扫描
   - 知识图谱「重建」按钮 → 「更新图谱」（连带确认弹窗文案）
   - grep 验证：上述旧词在面板文案中零残留（代码注释与文档层允许保留"归档"这一核心机制词）
2. **文案统一**：空态句式统一"暂无 X（去哪里做）"；按钮动宾结构统一（生成/打开/编辑/保存/删除/同步/重扫）；确认弹窗统一"将覆盖/删除 X，确认？"句式。
3. **Bug 修复**：时间页周模式下点跨月日期，左栏周视图锚点跟随选中日（weekDatesOf 以选中日所在周重算）。
4. **死样式清理**：P2 验收发现 src/panel.css 约 281、558-605 行残留 8 处 `.wl-fold*` 死规则（P1 删 reportsFold 时未清），DOM 已无对应元素，全部移除。
4. **README**：README.md 与 README_CN.md 的「面板」章节从旧 6 页签描述改写为 5 页签新 IA（今天/时间/资料库/报告/设置 + 一句各页职责），快捷命令/Agent 工具清单核对与 0.21.0 实际一致。
5. **回归审计**：对照 §10 清单逐条给出证据（3 次点击可达、唯一日历、无整页替换、无嵌套折叠、术语见词知义、覆盖/删除有确认、测试全绿）；发现小问题当场修，大问题写遗留。
