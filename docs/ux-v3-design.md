> v1.0 · 2026-11-02 · 状态：**v3 全部实施完成（P1=0.19.0 / P2=0.20.0 / P3=0.21.0）**

## 2. 设计原则（全局交互规范）

1. **主从布局，不做整页替换**。任何"点 X 看详情"都是右侧/下方详情区即时更新，不切换整页，永远有可见的返回坐标。
2. **日历全局唯一**。全面板只有一个日历组件（时间页），其余地方的"天"一律用日期筛选器或链接。
3. **高频平铺，低频折叠**。每天要碰的操作（勾待办、写日志、生成报告）平铺；一周碰不到的（模板、连接器、备份）进设置。
4. **一页一事**。每个页签回答一个明确的问题（见 §3）。
5. **表单三件套**：常量表单 + 显式「保存」+ 保存后 toast。没有自动进编辑态，没有渲染中套渲染。
6. **破坏性/覆盖操作必确认**。归档覆盖手写备注、恢复备份、删除连接器，一律弹确认并说明后果。
7. **术语白话**。按 §7 对照表全局清理，代码注释与文档同步。

## 3. 新信息架构：5 页签

```
┌──────────────────────────────────────────────────────────┐
│  今天        时间        资料库        报告        设置      │
└──────────────────────────────────────────────────────────┘
  回答"现在"    回答"某天"    回答"找历史"   回答"交出去"   回答"配置"
```

| 页签 | 回答的问题 | 内容（自上而下） | 替代的旧页面 |
| --- | --- | --- | --- |
| **今天**（默认） | 现在该干什么？ | ① 归档状态卡（未归档→「生成今日日志」主按钮；已归档→查看/继续编辑）② 今日待办：到期+逾期，直接勾选、就地快加，尾部「管理全部待办 →」③ 建议关注（推荐卡，采纳/忽略）④ 今天的 AI 会话（简表）⑤ 昨天回顾（昨日日志前 10 行 + 打开） | 概览（约 70% 内容，删统计卡墙、最近运行） |
| **时间** | 某天发生了什么？ | 左：唯一日历（月/周切换，格子 ≤3 标记：日志·到期·会话 + 选中态）；右：当日详情（当天待办可勾 / 当天日志阅读+编辑 / 当天会话 / 当天记录 / 「生成日报」按钮）。底部：「全部待办」管理区（筛选 chips + 分组 + AI 建议 + 批量解析，即原待办工作台整体搬入） | 日程（删当日枢纽）；待办工作台从日程页底部平移 |
| **资料库** | 找历史？ | 顶部子视图切换（segmented）：**会话 / 日志 / 图谱**。会话视图 = 筛选栏常驻（关键词/项目/来源/日期窗/标记/分组/仅工作相关）+ 列表 + 行展开详情，撤月历；日志视图 = 归档搜索 + 结果列表；图谱视图 = 实体类型 chips → 实体关系浏览（原样搬入） | 会话（撤月历、撤"三段式"）；日志·汇报页的搜索部分；图谱 |
| **报告** | 交出去什么？ | 顶部生成区平铺：类型（日报/周报/月报/季报/绩效/项目/自由总结）+ 范围 + AI 润色开关 → 「生成」；下方已生成报告列表（按类型分组、点开阅读） | 日志·汇报页的「汇报生成」折叠区（v0.13 深埋问题就此解除） |
| **设置** | 怎么配置？ | 左侧子导航 + 右侧表单页：通用（数据目录/扫描目录/git 作者/自动归档）· AI 接口（润色配置/扫描本机工具/模型）· 采集与调度（调度任务/会话来源开关/额外目录）· 连接器 · 提示词模板 · 备份与迁移 · 诊断（来源健康/最近运行/用量/缓存，从今天页迁入） | 设置（4 个异步折叠块全部改为子页面，消除渲染套渲染的架构土壤） |

**设计取舍（Ray 评审时可翻转的点）**：
- 待办工作台放「时间」页底部而非独立页签——若你觉待办该平级，加回来就是 6 页签，其余不动。
- 图谱归入「资料库」子视图而非独立页签——它属于"翻资料"低频动作。
- 概览的统计卡墙、项目卡删除——它们是 IA 不自明的补偿物，新骨架下不再需要。

## 4. 各页签交互细节

### 4.1 今天
- 归档状态卡：`今天未归档` + 主按钮「生成今日日志」；已归档显示生成时间 + 「打开」/「继续编辑」。
- 今日待办区：逾期红点、今日到期，勾选即完成（乐观更新 + 失败回滚）；输入框回车即加。
- 无任何跨页跳转按钮墙；「管理全部待办」是唯一链接，落到时间页待办区并滚动定位。

### 4.2 时间（核心改动：枢纽 → 主从）
- 布局固定：`┌ 日历(左 40%) ┬ 当日详情(右 60%) ┐`，下方通栏「全部待办」。
- 点天 = 右侧详情刷新，页面不滚不动，面包屑不出现——没有"进入/退出枢纽"概念。
- 当日详情内部自上而下：待办到期（可勾）→ 日志卡（阅读态 + 「编辑」）→ 会话（条数 + 前几条，点开进资料库预置日期）→ 记录（当天 git/文档/外部条目摘要）→「生成日报」。
- 日历格子标记收敛为 3 种：`●`有日志 `▼`有到期待办 `◦`有会话，外加选中态高亮；其余信息（条目数、报告）只在详情区出现。

### 4.3 资料库
- 会话视图：筛选栏一行常驻（下拉+输入框，非常规折叠），「同步会话」按钮在筛选栏右端；行点击展开详情（摘录/目录/文件），「加载完整摘录」保留。
- 日志视图：搜索框 + 日期范围，结果按天列表，点击在行下展开全文预览（新窗口式阅读不做，减少模式切换）。
- 图谱视图：保持现有 chips→实体列表，关系对端可继续点击。

### 4.4 报告
- 生成区常驻顶部（平铺，无折叠）：类型单选 chips、范围（随类型给默认值，可改）、AI 润色开关（未配置 AI 时禁用并提示去设置）。
- 已生成列表：类型分组 + 时间倒序；每条：打开 / 重新生成（覆盖前确认）/ 复制 Markdown。
- 生成完成后列表原位刷新并高亮新条目（不跳页）。

### 4.5 设置
- 左导航 7 项（§3 表），右表单页；每页独立「保存」，脏状态离开时提示。
- 原 4 个异步折叠块改为子页面后，加载时机 = 首次进入该子页（懒加载），失败显示错误 + 重试按钮，不再有折叠块展开触发的渲染连锁。
- 诊断页：每来源一行（上次扫描/文件数/错误/「重扫」），调度任务运行历史表，AI 用量，缓存大小 + 清理。

## 5. 关键行为统一

| 场景 | 旧行为 | 新行为 |
| --- | --- | --- |
| 写今天日志（未归档） | 概览点归档或日程点天→枢纽→生成日报 | 今天页主按钮一步直达 |
| 写/改任意一天日志 | 日志页点天载入→点"编辑" | 时间页点天→日志卡「编辑」；新旧日志行为一致（一律先阅读态，显式点编辑） |
| 生成周报 | 日志·汇报页展开折叠区 | 报告页顶部生成区，一步 |
| 查上周会话 | 会话页月历点天筛选 | 资料库会话视图日期范围筛选器（月历已撤） |
| 看某天全貌 | 日程点天→整页枢纽 | 时间页点天→右侧详情，不换页 |
| 找设置项 | 一页内翻折叠块 | 设置左导航按名直达 |

## 6. 不改的东西（明确划出范围）

- lib/ 全部数据层（entries/calendar/sessions/report/recommend/graph/templates/connectors/scheduler）零改动。
- MCP 工具名与参数、斜杠命令、SessionStart hook：本期不动（Agent 面收敛另立文档，见 §9）。
- 数据文件格式与旧归档兼容性。
- AI 配置扫描/复用逻辑。

## 7. 术语对照表

| 旧 | 新 | 理由 |
| --- | --- | --- |
| 当日枢纽 | （概念删除）→ 当日详情 | 删除自造范式 |
| 采集条目 / 统一条目 | 记录 | 见词知义 |
| 入库会话 | 已同步会话 | 动词明示 |
| 一键同步全部历史会话 | 同步会话 | 去营销腔 |
| 指纹扫描 | 增量扫描 | 通用词 |
| 补偿式调度 | 定时任务（错过的自动补跑） | 去实现细节 |
| 知识图谱「重建」 | 更新图谱 | 用户视角是更新不是重建 |
| 归档（按钮文案） | 生成今日日志 | 按钮说结果不说机制；"归档"保留在文档层 |
| 汇报生成 | 报告 | 页签名即动词 |
